## 简介

Mistveil 是一个新标签页扩展，把浏览器默认那个空白页换成一个安静、干净、属于你自己的入口，基于DeepSeek（doge），哦鲸鲸。

打开新标签页，屏幕中央只有一个搜索框，安静地待在那里。想找东西就搜，不想用就当作背景。左侧、右侧、底部各藏着一条滑出的面板，鼠标靠近才现身，平时完全隐形。

没有广告，没有推荐流，没有"热门资讯"，只有一个搜索框和你自己配置的东西。

## 使用办法

1.下载后，解压文件夹。

2.打开浏览器的开发者模式。

3.点击**加载未打包的扩展程序**，然后选择解压的文件夹，或者直接把文件夹拖到浏览器的扩展界面。

## 壁纸打开方式

鼠标滚轮↑ ———— 打开

鼠标滚轮↓ ———— 关闭
